# Maxwell Growth App — Landing

Landing page en **Astro 5 + Tailwind CSS 4**, rama de trabajo `ender`.

## Desarrollo

```bash
npm install
npm run dev
```

## Build / Vercel

```bash
npm run build
```

Framework preset: **Astro**. Output: `dist/`.

## Imágenes

Los PNG de `Untitled (1)/` se convierten a WebP en `public/images/` (calidad 90–95, misma resolución).

```bash
npm run optimize:images
```
